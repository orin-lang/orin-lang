# 06-generic-stack

Write a generic `Stack<T>` class (`push`, `pop`, `peek`, `size`, `isEmpty`) with a generic method `mapTo<U>(f)` returning a `Stack<U>`, and a bounded generic function `largestOf<T extends Ord>`. Demonstrate them with an `int` stack.

Rules: use only the published documentation; the files in this directory are the final program (`main.or`), the expected output (`expected.out`) and, where the program reads input, `stdin` and `args`.
