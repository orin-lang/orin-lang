# 09-set-orderedmap

Write an Orin program that uses `Set<string>` (add, has, remove, union, intersection, difference) and `OrderedMap<string, int>` (set, get, remove, entries in key order, first/last/floor/ceil keys) from std:collections.

Rules: use only the published documentation; the files in this directory are the final program (`main.or`), the expected output (`expected.out`) and, where the program reads input, `stdin` and `args`.
