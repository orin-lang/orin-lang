# 01-wordfreq

Write an Orin program that reads text from standard input and prints each distinct word with its count, most frequent first, ties in alphabetical order, one `word count` per line. Words are separated by spaces; matching is case-sensitive.

Rules: use only the published documentation; the files in this directory are the final program (`main.or`), the expected output (`expected.out`) and, where the program reads input, `stdin` and `args`.
