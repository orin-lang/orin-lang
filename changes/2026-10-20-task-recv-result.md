- **std:task: recv() and sleepUntil return Result (freeze C6).** `Receiver.recv()` now returns `Result<T, TaskError>` instead of `Option<T>`: `Ok(v)` for a value, `Err({kind: Closed})` once the channel is closed and drained (end of stream); `sleepUntil(deadline)` returns `Result<void, TaskError>` (`Ok()` today), so both can report cancellation later by adding a `TaskErrorKind` member. Update `match (rx.recv()) { Some(v) => .., None => .. }` to `Ok(v) / Err(e)`. `TaskHandle.join()` is documented as not a cancellation checkpoint (use `joinUntil`/`joinTimeout`). std:task is unstable, so there are no deprecated wrappers.
