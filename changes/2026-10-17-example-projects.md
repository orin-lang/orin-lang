- **Example projects.** `examples/projects/notes-service` (a concurrent JSON service on `std:net`/`std:http`/`std:task`/`std:json`; one owner task holds the store, workers talk to it over channels) and `examples/projects/wc` (a `wc`-style CLI with flags, stdin and exit codes) are packages to copy, each with several modules, unit tests and a README; `tools/test_example_projects.py` builds and tests both, runs `wc` on fixed inputs and drives the service over HTTP, in the `assurance` CI job.
