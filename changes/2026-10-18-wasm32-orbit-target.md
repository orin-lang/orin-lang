- **WebAssembly target `wasm32-orbit` (ADR-0055).** `orin build --target=wasm32-orbit` (and `orin compile --target=wasm32-orbit`) builds the second WebAssembly target next to `wasm64-orbit`: Orin values stay 64-bit and only C pointers are 4 bytes, so programs, manifest, imports and the 1043-test conformance result are the same, the module is 8 % smaller, and it runs as fast as or faster than wasm64 (nbody 1.4-1.8x, bintrees up to 1.27x) and in engines without Memory64.
