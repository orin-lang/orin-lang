- **Compiler callees state what they return (ADR-0053 Addendum A, group U1).** The verifier reads a call only through the callee's contract, so a predicate or accessor without an `@Ensures` is a free value in every caller's counterexample (the "depends on a value the model does not know" UNKNOWN). The compiler sources now give the O(1) helpers that callers rely on the missing, true clauses: the body as a result equation for `isKindNumber`, `kindSigned`, `kindNarrow`, `kindUnsigned64`, `i64Min`, `isDigit`, `isJsonSpace`, `isKind`, `isLs`, `lsKind`, `lsSrc`, `lsEq`, `ownedLike`, `leaky`, `isLive`, `isAggClass`, `localClass`, `spanEq`, `covers`, `hasSpan`, `paramsWellFormed` and the accessors `count`/`size`/`strings`/`vtables`/`depth`/`hasSummary`; `kindBits` and `hexVal` get the per-case values; `isValidCode` is written out over its five fixed characters (no loop) and states the full equivalence `result == (length 5, `E`/`W`, four digits)`, so a `diag` call on a literal code becomes provable once the verifier knows literal contents; `rtNames().length == RT_LIVE_COUNT + 1`, with the same bound as an invariant of `CSymbols` and `LlvmSymbols` (so `rtLoaded(this.rt)` is provable); `succCount`, `succAt`, `tyClass`, `opLocalOk` and the `mty*` predicates answer per variant; `isWellFormedFunction`, `fnShapeOk`, `emittable` and friends state the O(1) facts they imply. `isWarning` now tests the first character (`charCodeAt(0) == 87`) so that `diag`'s own `@Ensures` can be proved. No contract was removed or weakened and none costs more than a few comparisons under `--check-contracts`.
