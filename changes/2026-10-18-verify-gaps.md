- **The contract verifier closes three gaps that left the compiler with UNKNOWN (ADR-0053 Addendum A).** A `match` statement whose arms all `return` no longer looks like a function that falls off its end ("return statements do not match the declared result type"); a parameter, field or result of an interface type is an opaque value (a class converts to it at a call) instead of being outside the fragment; and a private method assumes the class invariants on entry when every call of it provably holds them, so its contracts that need them can be proved (a helper called in the middle of an update does not get them). Wrong claims about such code are still REFUTED.
