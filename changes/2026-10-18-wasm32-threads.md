- **Real threads on `wasm32-orbit` (ADR-0055 decision 9).** Programs that use `std:task`, channels or `.parallel()` now run on Orbit as natively: tasks run at the same time (ping-pong and pipelines over bounded channels work) and a task that traps reaches its join. The module imports a shared memory and `orbit:thread/v1 spawn`, blocks with `memory.atomic.wait32`, and the manifest of a task program lists `thread/v1`; `wasm64-orbit` keeps running tasks one at a time. A deadlock of that sequential path now exits with status 134, as natively.
