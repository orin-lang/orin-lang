- **Environment variables: `std:process` `env` (ADR-0027).** `env(proc, name): Option<string>` reads an environment variable through the process grant (`None` when unset, `Some("")` when set and empty); `ORIN_DENY=process` makes it trap like `args`. It is the effect `Process.Env` (INPUT, `ProcessGrant`). On `wasm32-orbit` and `wasm64-orbit` it maps to `orbit:process/v1` `env_get`, and the module's manifest lists `process/v1` only for programs that use `args`, `env` or stdin, so task programs still need no process capability. `tools/run_tests.py` gains a `// env: NAME=value` header and `tools/wasm_run.mjs` a `--env NAME=VALUE` option.
