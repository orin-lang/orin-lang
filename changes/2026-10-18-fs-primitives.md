- **L0 and `std:fsraw` primitives for rename, remove and atomic write (freeze item C4).** The platform layer gains `orin_platform_file_rename`, `orin_platform_file_remove` (unlink), `orin_platform_dir_remove` (rmdir) and `orin_platform_file_write_atomic` (temporary file next to the target, fsync, rename over it, directory fsync); the runtime exposes them as `orin_fs_rename`, `orin_fs_remove_file`, `orin_fs_remove_dir` and `orin_fs_write_file_atomic`, and `std:fsraw` as `fsRename`, `fsRemoveFile`, `fsRemoveDir` and `fsWriteFileAtomic` (`Result<void, string>`, same grant checks as `fsWriteFile`, refused by a read-only grant; a symbolic link is renamed, removed or replaced itself, never its target); the public `std:fs` functions follow separately.
