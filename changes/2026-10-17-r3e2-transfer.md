- **Task interface, steps 2 and 3: value transfer, lending and the thread count in Orin (ADR-0052 Addendum B, R3e.2/R3e.3).** `runtime/core/transfer.or` implements the value transfer of `std:task` (the slot table with generation tokens, the move-or-copy decision, the iterative uniqueness walk and deep copy, the move/copy counters, the box-once path and the void box), `runtime/core/lend.or` the pinning lend of `.parallel()` and `runtime/core/task.or` the thread count of parallel pipelines (`ORIN_THREADS`), so generated code no longer calls the C `orin_rt_transfer_*`, `orin_rt_lend` and `orin_rt_par_threads`. The slot table moves into the shared block, with a slot layout that both the Orin and the remaining C code (task start) use, so the two share one table. Moves, copies and every `ORIN_STATS` counter are unchanged; there is no user-visible change. A new test `tests/concurrency/transfer_deep.or` moves and copies 200,000-link chains, a million integers and 100,000 strings.
