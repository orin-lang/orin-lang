- **Task interface, step 1: core operations `plat`, `fnAddr`, `sharedBase` and the monitor operations in Orin (ADR-0052 Addendum B, R3e.0/R3e.1).** The runtime dialect gains three operations that only `$rt/` files can use: `plat(k, ...)` calls one of 20 platform-layer functions (threads, monitors, process) directly, `fnAddr(k)` yields the address of a runtime entry's C-ABI wrapper, and `sharedBase()` the address of the shared block `orin_shared`. The heap block gets room for the task interface (offsets 336..376). `runtime/core/sync.or` implements the eleven monitor operations of `std:task` in Orin on top of `plat`, so generated code no longer calls the C `orin_mon_*` functions, and the four L0-shaped hooks (environment, runtime lock, stderr line) are replaced by `plat`. Programs that do not use tasks emit byte-identical code; there is no user-visible change.
