- **Unchecked struct slots (ADR-0038 lever 2, T7; MIR v2.8).** A `getfield` / `setfield` of a heap struct whose slot an earlier access of the same struct local in the block already checked (that slot or a higher one) is compiled without the kind and slot-count check, in both backends. New MIR instructions `IGetFieldU` / `ISetFieldU`, verifier rule U6 (`compiler/verify/fieldcheck.or`) and an optimiser pass (`compiler/opt/fieldcheck.or`) that asks the same rule; mutation classes `field-*` in `tools/mutate_mir.py`. `--assert-facts` does not re-check these. The first access of a block is covered too: a new `IShapeCheck(o, k)` in front of it performs the one check for the highest later slot.
