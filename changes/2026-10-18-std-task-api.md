- **std:task follows ADR-0048.** `std:taskcore` is now the internal module `std:task/internal` (`library/std/task_internal.or`; importing it from user code warns W0493), `Ring`, `Ledger` and `Ranges` are no longer re-exported from `std:task`, the test hooks `movedCount()` / `copiedCount()` moved there too, the raw-handle fields of `Sender`, `Receiver`, `Scope` and `TaskHandle` are private, `Sender.send` returns `Result<void, TaskError>` with `Err({kind: Closed})` instead of a `bool`, `parallelMap` is deprecated in favour of `xs.parallel().map(f)` (W0440), and every public item has a signature-first doc comment; `std:task` is unstable, so there are no wrappers for the removed names.
