- **A cancelled network wait can no longer report an OS error.** `std:net` calls blocked in accept, connect, recv or send return `Err(Cancelled)` whenever the task's token or an ancestor is set, also when the wait could not make its own wake descriptor (`EMFILE`, which a task saw as `Os`) or `poll` itself failed; a set token is now read before any descriptor is created (L0 `net_wait`/`wake_walk`), with a regression check in the platform tests.
