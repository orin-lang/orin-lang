# Orin

**Build with agents. Verify with the compiler. Understand the change.**

Orin is a TypeScript-familiar, natively compiled language for verifiable software engineering: value semantics,
ownership checking, contracts, and semantic change analysis. It is an experimental alpha: expect missing features and
breaking changes, and read the [stability policy](stability.md) before depending on anything.

## Install

```sh
brew install orin-lang/orin/orin
```

Other platforms and the one-line installer are described in [Install](install.md).
