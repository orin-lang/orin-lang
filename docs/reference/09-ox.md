# 9. OX markup

Normative. Sources: ADR-0043 (syntax and lowering), ADR-0044 (generic providers), `docs/ox.md`, `compiler/check/ox.or`,
`compiler/check/expr.or`, `library/std/ox.or`, `library/std/html.or`. Conventions: see [README](README.md).

OX is TSX-like markup. The language owns the syntax; a *provider* module owns the meaning. The std provider is `std:html`.

## 9.1 Syntax

**OX-1. Provider declaration.** A file that contains markup has exactly one `import ox from "M";`, where `M` is any module. It
binds no name. There is no default provider. Markup without it is E0490.
Tests: tests/next/errors/ox_no_provider.or, tests/next/run/ox_basic.or.

**OX-2. Where `<` starts an element.** `<` starts an element only when the previous token is `(`, `,`, `=`, `=>`, `?`, `:`, `{`,
`[`, `return`, an operator or `${`, and a tag name or `>` follows. After a name, a literal, `)`, `]` or `}` it is the
less-than operator or the start of type arguments.
Tests: tests/next/run/ox_lexer.or.

**OX-3. Elements.** Grammar (informal):
`element = "<" tag { attr } ( "/>" | ">" { child } "</" tag ">" ) | "<>" { child } "</>"`. A lower-case tag consists of letters, digits,
`-` and `_` (`<my-widget>`); an upper-case first letter names a component; a dotted path whose last segment starts upper-case
is a member tag. A fragment `<>..</>` has no attributes: `<>` is one opening and has no position for one, and `< class="x">` (a space after `<`) is not markup (OX-2). A closing tag must repeat the opening tag exactly; an element
that is not closed, or a mismatched closing tag, is a syntax error (E0100 for an unclosed element, E0200 for a mismatch).
A `{` or `}` in text (E0100) and a dotted tag whose last segment is lower-case (`<ui.card>`, E0200) are syntax errors. Two written attributes
of the same name on one element are E0200.
Tests: tests/next/run/ox_basic.or, tests/next/errors/ox_unclosed.or, tests/next/errors/ox_mismatched_close.or,
tests/next/errors/ox_brace_in_text.or, tests/next/errors/ox_duplicate_attr.or, tests/next/errors/ox_member_lowercase.or,
tests/next/errors/ox_member_mismatched_close.or, tests/next/errors/ox_fragment_attribute.or.

**OX-4. Attributes and children.** An attribute is `name="s"`, `name='s'` (TSX rules: no backslash escapes, entities decoded),
`name={e}`, a bare `name` (the value `true`) or a spread `{...e}`. Text children are trimmed per line and joined with one
space (the TSX rule: leading blanks of every line but the first and trailing blanks of every line but the last are dropped, empty lines vanish, blanks inside a line are kept), entities decoded.
`{e}` is an expression child. Namespaced names (`xlink:href`) are a syntax error (E0100). `key` has no special meaning: it is an ordinary attribute. An invalid
tag or attribute name is E0494.
Tests: tests/next/run/ox_basic.or, tests/next/run/ox_entities_and_quotes.or (entities in text and attributes, the single-quoted form, no backslash escapes),
tests/next/run/ox_text_trim.or, tests/next/run/ox_key_is_plain.or, tests/next/errors/ox_namespaced_attribute.or, tests/next/errors/ox_bad_tag.or.

**OX-5. Spread.** `{...r}` requires a record (E0492 otherwise) and is evaluated once. When a name occurs more than once,
through spreads or written attributes (ASCII case-insensitive), the one written later wins; every value is still evaluated
exactly once, in source order.
Tests: tests/next/run/ox_spread_intrinsic.or, tests/next/errors/ox_spread.or, tests/next/errors/ox_spread_field_type.or.

## 9.2 Providers

**OX-6. Provider function.** `M` exports `function ox()` whose body is a single `return` of a `Markup<R> { .. }` or
`Components<R> { .. }` literal (types from `std:ox`). It is type-checked but never called; anything else is E0490.
Tests: tests/next/errors/ox_provider_not_literal, tests/next/errors/ox_no_provider.or.

**OX-7. `Markup<R>` serialises text.** Lower-case tags are written into one buffer, and the result of a root is `wrap(buffer)`.
Static text and static attribute values are encoded at compile time with the `escapes` table; computed strings use `text` /
`attr`. A tag in `voidTags` ends with `voidEnd` and has no children (E0494). Children of a `rawTextTags` tag are static text
only, unencoded, without `</`; a computed child is E0493. A number child or attribute is its decimal text. A child of type
`R` / `R[]` is embedded with `embed` / `embedAll`.
Tests: tests/next/run/ox_basic.or, tests/next/run/ox_xml, tests/next/run/ox_escape_diff.or, tests/next/run/html_escape_pieces.or,
tests/next/run/ox_capacity.or, tests/next/errors/ox_void_children.or, tests/next/errors/ox_script_dynamic.or.

**OX-8. Attribute rules.** An `AttrRule { names, prefix, convert }` matches attribute `a` when `a` is in `names` or starts with a
non-empty `prefix` (ASCII case-insensitive). A computed string value goes through the `convert` of the first matching rule, else
`attr`. A matching rule with `convert: None` makes any computed value (also a spread field) E0493. With `Option<T>`: `None`
writes nothing, `Some(v)` as `a={v}`; a `convert: None` rule still rejects it.
Tests: tests/next/errors/ox_event_handler.or, tests/next/errors/ox_spread_event.or, tests/next/errors/ox_option_static_only.or,
tests/next/errors/ox_static_only_rule, tests/next/run/ox_xml.

**OX-9. Presence attributes.** A `bool` attribute (or a bare attribute) writes the name when true and nothing when false if the
provider sets `presenceAttrs: true`; otherwise E0492. A `bool` child is E0492.
Tests: tests/next/errors/ox_presence_attr, tests/next/errors/ox_spread_presence, tests/next/errors/ox_bool_child.or.

**OX-10. `Components<R>` builds values.** An intrinsic tag `t` is the call of the provider's exported function `t`; text where an
`R` is expected is `text(s)`, several children where one `R` is expected are `fragment([..])`.
Tests: tests/next/run/ox_widgets, tests/next/run/ox_member_widgets, tests/next/run/ox_components_text_slot (text in a slot of type `R[]` is one `text(s)` per text child; several children for one `R` are a `fragment`).

**OX-11. Wrong value types.** A child or attribute whose type the provider cannot place (an `Html` in an attribute, a child of
the wrong type in a slot) is E0492; an attribute of the wrong type for a component parameter is E0400.
Tests: tests/next/errors/ox_html_in_attr.or, tests/next/errors/ox_child_wrong_type.or, tests/next/errors/ox_slot_child_type,
tests/next/errors/ox_attr_type.or.

## 9.3 Components

**OX-12. Component call.** An upper-case tag `C` is a call of the function `C` in scope; each attribute fills the parameter of the
same name; `{e}` is checked against the parameter type. An unknown component or one that is not a function declared with
`function`, an unknown attribute and a missing attribute are E0491. A parameter of type `Option<T>` may be omitted (it is `None`).
Attributes are evaluated left to right in source order into temporaries, once each, even when the parameters are declared in another order.
Tests: tests/next/run/ox_components.or, tests/next/run/ox_widgets (`<Order c={..} a={..} b={..} />` prints `eval c`, `eval a`, `eval b`, then the call), tests/next/errors/ox_component_unknown.or, tests/next/errors/ox_unknown_attr.or,
tests/next/errors/ox_missing_attr.or.

**OX-13. Children and slots.** Children fill the parameter `children`; `<:name>..</:name>` fills the parameter `name`, directly
inside a component or member tag. An attribute and a slot for one parameter, a slot without a parameter, children for a
component without `children`, and a slot on an intrinsic element are E0491. A slot is converted according to the type of the
parameter: `R` of a `Markup` provider (the fused buffer), `R` of a `Components` provider (the single child, else
`fragment`), `E[]` (an `{x}` of type `E[]` is spliced), `Option<E>` (none or one child; more is E0491), `string`
(concatenation, not encoded), any other type (exactly one child). A slot with no children is the empty value of the type.
Whitespace-only text is dropped.
Tests: tests/next/run/ox_components.or, tests/next/errors/ox_attr_and_slot.or, tests/next/errors/ox_children_no_param.or,
tests/next/errors/ox_slot_no_param.or, tests/next/errors/ox_slot_missing.or, tests/next/errors/ox_option_slot_two.or.

**OX-14. Member tags.** `<ui.Card ..>` calls the method `Card` of the value `ui` (a class instance or an interface value;
`this.Row` inside a class; a path of field reads is allowed), with the rules of OX-12 and OX-13. `<Ui.Card ..>` where `Ui` is a
class and not a value in scope calls the static method. An instance method called this way is E0491; an unknown member, a
field that is not a method and an unknown attribute are E0491; a private static method is E0405.
Tests: tests/next/run/ox_member_tags.or, tests/next/run/ox_member_static, tests/next/run/ox_member_widgets,
tests/next/errors/ox_member_unknown.or, tests/next/errors/ox_member_unknown_attr.or, tests/next/errors/ox_member_closure_field.or,
tests/next/errors/ox_member_static_attr.or, tests/next/errors/ox_member_static_instance.or,
tests/next/errors/ox_member_static_unknown.or, tests/next/errors/ox_member_static_private.or.

## 9.4 Safety

**OX-15. `@Sealed`.** A record type marked `@Sealed` (the std type `Html`, and any user record) can be built by a record literal
and have fields assigned only in its own module; elsewhere E0495. `@Sealed` on a non-record is E0440. Raw HTML is only made by
`trustHtml(raw)`.
Tests: tests/next/errors/ox_sealed_literal.or, tests/next/errors/ox_sealed_assign.or, tests/next/errors/ox_sealed_user,
tests/next/errors/ox_sealed_non_record.or, tests/next/errors/jsonnumber_sealed_literal.or,
tests/next/errors/jsondecode_sealed_literal.or.

**OX-16. `std:html` escaping.** With `std:html` every computed string is escaped (`& < > " '`) and static text is escaped with the
same table at compile time; URL attributes (`href`, `src`, `action`, ...) with a computed value are sanitised
(a relative URL and the schemes `http`, `https`, `mailto` and `tel`, ASCII case-insensitively, are kept; every other scheme, and one written with a leading space, a control character or a TAB, becomes `about:invalid#orin-unsafe-url`); computed `on*` attributes are E0493; `<script>` / `<style>`
take only static text. Compile-time and run-time encodings agree.
Tests: tests/next/run/ox_escape_diff.or, tests/next/run/ox_url_schemes.or, tests/next/run/html_escape_pieces.or, tests/next/errors/ox_event_handler.or,
tests/next/errors/ox_script_dynamic.or.
